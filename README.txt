REDLINE — Toykoo-inspired demo homepage

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in a browser.
3. For best results, use VS Code + Live Server.

INCLUDED
- Responsive homepage layout
- Black / racing red / white theme
- Navigation and mobile menu
- Search/filter product cards
- Add-to-cart drawer with subtotal and remove item
- Wishlist hearts, FAQ accordion, newsletter demo

IMPORTANT
This is an original demo storefront inspired by the general structure of a collectible-car shop.
Product names, prices, logo and copy are placeholders. Product imagery uses remote Unsplash URLs.
Cart and newsletter are front-end demos only. No real checkout, database, inventory, login or order processing is connected.
Replace placeholder products, images, policies and branding before publishing.
